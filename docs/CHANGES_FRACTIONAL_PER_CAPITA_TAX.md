# 1인당 지방세 소수 원 단위 정규화 변경

## 배경

봉화군 2024년 1인당 지방세 부담 원천은 `주민1인당 부담금액`과
`세대당부담금액`을 각각 `1152975.163`, `2002842.879`로 제공한다. 두 값은
총 지방세액을 인구수와 세대수로 나눈 결과를 소수 셋째 자리까지 반올림한 값이며,
기존 정수 전용 금액 검증은 이를 오류로 분류해 행 전체를 격리했다.

## 변경

- 1인당·세대당 부담금액에 한해 유효한 비음수 소수 금액을 허용한다.
- PostgreSQL의 원 단위 `bigint` 모델에 맞춰 가장 가까운 원으로 반올림한다.
- 반올림한 필드는 `fractional_won_rounded` 정보성 품질 이슈로 기록하며 원문 값과
  정규화된 원 단위 값을 함께 남긴다.
- 총 지방세액을 비롯한 다른 금액 필드는 기존 정수 검증을 유지한다.
- 봉화군 실제 소수 형식과 반올림 결과를 회귀 테스트로 추가했다.
