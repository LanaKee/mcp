# 모델별 Vanilla vs MCP 비교 — 경상북도 컨텍스트

같은 문항·같은 지시문·같은 채점기를 네 모델에 각각 적용했습니다. 각 모델 안에서 두 arm의 유일한 차이는 경상북도 데이터 계층 접근 여부입니다.

**모델 간 절대 점수 비교는 이 벤치마크의 목적이 아닙니다.** 문항이 22개뿐이고 일부 모델은 temperature를 고정할 수 없어, 모델 순위를 매기기에는 표본이 부족합니다. 읽어야 할 값은 각 모델 *내부*의 vanilla → MCP 변화량입니다.

## 정확도

| 모델 | vanilla | MCP | 변화 |
| --- | ---: | ---: | ---: |
| `claude-sonnet-5` | 50.0% | 81.8% | +31.8p |
| `gpt-4o-mini` | 27.3% | 72.7% | +45.5p |
| `gpt-5.6-luna` | 36.4% | 81.8% | +45.5p |

## 환각 — 답변한 것 대비

전체 대비 환각률은 답을 회피할수록 좋아 보이므로, 실제로 값을 단언한 답변만을 분모로 삼은 수치를 함께 싣습니다. 답변 시도율이 낮은 모델의 환각률은 그 자체로는 의미가 없습니다.

| 모델 | 답변 시도율 (V→M) | 환각률(답변 대비) V | 환각률(답변 대비) M | 변화 |
| --- | ---: | ---: | ---: | ---: |
| `claude-sonnet-5` | 100.0% → 81.8% | 50.0% | 16.7% | -33.3p |
| `gpt-4o-mini` | 27.3% → 81.8% | 33.3% | 22.2% | -11.1p |
| `gpt-5.6-luna` | 100.0% → 77.3% | 63.6% | 11.8% | -51.9p |

## 읽는 법

- 정확도는 유효 실행 3개 중 3개에서 MCP arm이 더 높습니다.
- vanilla의 답변 시도율은 모델마다 크게 갈립니다: `gpt-4o-mini` 27.3% 대 `claude-sonnet-5` 100.0%, `gpt-5.6-luna` 100.0%. 약한 모델은 침묵으로, 강한 모델은 단언으로 실패합니다. 즉 모델을 키우는 것만으로는 환각이 사라지지 않고 더 그럴듯해질 뿐이며, 근거 계층이 필요한 이유가 여기에 있습니다.
- 지연은 유효 실행 3개 중 2개에서만 MCP arm이 더 깁니다. 장황하게 추론하는 모델에서는 도구 실행을 포함한 MCP arm이 오히려 더 빨랐습니다.
