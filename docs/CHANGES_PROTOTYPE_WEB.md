# 변경: `/prototype` 웹 화면 추가

## 배경

`apps/web`는 에이전트 응답을 그대로 펼쳐 보이는 진단용 화면이다. 데이터셋 후보,
도구 호출, 근거, 한계가 전부 텍스트로 나열된다. 시스템을 감사하기에는 좋지만,
"상주에서 스마트팜 창업을 준비하는 34세"가 읽을 화면은 아니다.

문제는 표현만이 아니다. 언어 모델을 붙여 자연어로 요약하게 하면 **줄글 한 덩어리**가
나오고, 사용자는 그 문장이 데이터에서 온 것인지 모델이 지어낸 것인지 구분할 수 없다.
이 프로젝트에서 그것은 가장 큰 실패다.

## 무엇을 만들었나

`prototype/` (`@gb/prototype`) — Next.js 15 App Router, TypeScript, Tailwind v4,
framer-motion, lucide-react.

### 1. 답변을 "그린다"

모델은 문장을 쓰지 않는다. `src/lib/blocks.ts`에 정의된 블록 스키마에 맞는 JSON만
낼 수 있고, 화면은 그 JSON을 카드로 렌더링한다.

| 블록 | 쓰임 |
| --- | --- |
| `headline` | 결론 한 줄과 부제 |
| `metric` | 큰 수치 하나 + 상태 배지 |
| `metricGrid` | 페르소나 브리핑(감면율·통과 안건·밀도 등) |
| `series` | 연도별 막대 그래프 |
| `table` | 검색 결과 목록 |
| `bullets` | 근거·해석 시 주의 |
| `callout` | 비어 있는 데이터셋, 답할 수 없음, 백엔드 장애 |

자유 마크다운이나 HTML을 받지 않는다. 받으면 모델이 표 대신 문단을 쓰기 시작하고,
주입 위험도 함께 들어온다.

### 2. 근거가 먼저, 표현이 나중

```
질문 → /api/chat → MCP /api/agent  (카탈로그 검색 · 도구 호출 · 근거 수집)
                 → claude-sonnet-5 (근거를 블록으로 배치)
                 → zod 검증 → 렌더링
```

모델에게 주는 것은 에이전트가 도구 호출로 실제 받은 값뿐이고, 프롬프트는 수치를
그대로 옮기고 직접 계산하지 말라고 못 박는다. `evidenceContract.cannotClaim`에
적힌 주장은 어떤 블록에도 넣지 못하게 했다.

### 3. 스키마 위반은 거절이 아니라 보정

처음에는 상한(항목 8개 등)을 어긴 응답을 통째로 버렸다. 실제로 첫 실측에서
`bullets.items`가 12개라는 이유로 근거를 다 모아 놓고도 폴백으로 떨어졌다.

지금은 길이와 개수를 잘라서 받아들이고, 형태가 아예 다른 블록만 버린다. 남는 블록이
하나도 없을 때만 결정적 렌더러(`lib/fallback.ts`)가 근거에서 직접 카드를 만든다.

### 4. 백엔드가 없으면 답하지 않는다

MCP 서버에 연결하지 못하면 모델을 호출하지 않고 연결 실패를 카드로 표시한다.
근거 없이 그럴듯한 답을 만드는 경로를 코드에 두지 않았다.

### 5. 에이전트 경로를 계속 노출한다

`RoutePanel`에 카탈로그 후보와 일치 용어, 실제 호출한 도구와 인자 전체, 안전 경계가
막은 호출, 비어 있던 데이터셋, 결합 키와 caveat이 그대로 들어간다. 브리핑 화면으로
바꾸면서 감사 가능성을 잃으면 `apps/web`가 증명하던 것을 되돌리는 셈이다.

### 6. 개인정보

지역·나이·관심분야는 `sessionStorage`에만 있고 질문 앞에 `[34세 · 상주시 · 스마트팜]`
형태의 맥락 문자열로만 붙는다(에이전트 API 상한인 500자에 맞춰 자른다). 대화 기록도
브라우저 `localStorage`에만 남고 사이드바에서 지울 수 있다. 서버는 아무것도 저장하지
않는다.

목업에 있던 계정 카드·업그레이드·로그아웃은 넣지 않았다. 인증이 없는데 로그인된
것처럼 보이는 화면은 거짓말이다. 같은 자리에 현재 맥락과 저장 정책을 표시했다.

## 화면

| 경로 | 내용 |
| --- | --- |
| `/` | 지역·나이·관심분야 입력 |
| `/ask` | 자유 질문 + 대표 질문 칩(`/api/questions` 프록시) |
| `/chat` | 사이드바 + 대화. `?q=`로 링크 진입 가능 |
| `/guide` | 이 화면이 보장하는 것과 하지 않는 것 |

## 검증

- `pnpm --filter @gb/prototype build` / `typecheck` 통과.
- `vitest run prototype` 17건 통과(블록 스키마 보정, 폴백 렌더러, 컴포저 실패 경로,
  페르소나 질문 조립).
- 실제 DB가 붙은 MCP 서버에 대해 두 질문을 종단 실행하고 headless Chrome으로 렌더링
  확인:
  - 「포항시는 2018~2024년 인구는 줄었는데 지방세 세수는 늘었나?」 → 인구 시계열
    막대와 2024년 지방세 단일 관측치를 그리고, 비교 시점이 하나뿐이라 증감을 판정할 수
    없다는 사실을 callout으로 표시.
  - 「[34세 · 상주시 · 스마트팜 · 창업] 나한테 해당되는 정책이 뭐가 있어?」 →
    `policy_program`이 비어 있다는 사실을 그대로 노출하고 답을 만들지 않음.

## 실행

```bash
pnpm dev            # MCP 서버 (127.0.0.1:8787)
pnpm prototype:dev  # 프로토타입 (localhost:3100)
```

`CLAUDE_API_KEY`는 루트 `.env`에서 읽는다. 주소·모델을 바꾸려면
`prototype/.env.local`을 쓴다.
